# WovenFabricPredictor-ANN
Rapid Mechanical Surrogate for Woven Ceramic Fabrics (Pre-release)

# Overview
A neural network-based surrogate modeling framework for rapid mechanical property prediction of 2D woven ceramic fabrics.  (Please note that this is a pre-release version. The codes will be updated post-publication.)

![image](https://github.com/mintg911/WovenFabricPredictor-ANN/blob/main/Model/figs/Image_Abstract-2.png)


# Key Features

-   **Parametric Modeling Framework:**
Characterizes 2D woven fabric architectures using three topological parameters, enabling systematic exploration of the design space.
    
-   **Automated Simulation Pipeline:**
Python-driven numerical analysis system for efficient evaluation of tensile and shear properties, validated against experimental data with high accuracy.
    
-   **ANN Surrogate Model:**
Trained on a comprehensive property database to capture complex correlations between weave architecture and mechanical performance, achieving orders-of-magnitude speedup over direct simulation.
    
-   **Integrated Resistance Factor:**
A novel metric for holistic assessment of mechanical performance, revealing that plain weave architectures exhibit optimal combined tensile-shear resistance.
